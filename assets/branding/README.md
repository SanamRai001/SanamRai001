# Sanam Rai — Brand Identity

This directory contains the visual identity used across my GitHub profile and selected project READMEs.

## Primary assets

- `logo-mark.svg` — primary dark app/avatar mark.
- `logo-flat.svg` — simplified transparent mark for small sizes and flexible placement.
- `brand-lockup.svg` — SR mark + Sanam Rai wordmark.
- `brand-board.svg` — visual identity reference.

## Brand language

**Positioning:** backend · systems · AI  
**Signature:** Build · Learn · Improve  
**Supporting line:** Systems for a better tomorrow.

## Core colors

| Token | Hex | Use |
|---|---|---|
| Electric Blue | `#3882F6` | primary accent |
| Cyan | `#22D3EE` | highlights / motion |
| Ice White | `#F8FAFC` | logo and primary text |
| Slate | `#94A3B8` | secondary text |
| Deep Ink | `#0B0F14` | dark surfaces |

The glossy dark-tile treatment is the expressive version. The flat mark should be preferred when the logo needs to remain legible at small sizes or on a busy background.
